Flexbox

Flexbox es un modelo de alineacion basado en 1 dimension, es decir solo alinea los objetos de forma vertical o de forma horizontal (una a la vez)

Para activar la distribuicion flexbox solo se necesita configurar al contenedor padre para alinear segun flexbox, utilizamos el comando

display: flex;

Flexbox tiene varias configuraciones o atributos que permiten cambiar la forma en la que se ve flexbox como:

flex-direction

La propiedad flex-direction configura el eje en el cual se desarrolla el flexbox (horizontal o vertical)

Barra Horizontal

En este caso para poner un flexbox horizontal usamos el valor row (fila) en la propiedad flex-direction

Barra Vertical

En este caso para poner un flexbox horizontal usamos el valor column (columna) en la propiedad flex-direction

justify-content

La propiedad justify-content alinea y distribuye los objetos hijos del flex a traves de su eje principal

align-items

La propiedad align-items alinea los elementos hijos del flex a traves del eje perpendicular al eje principal

flex-wrap

La propiedad flex-warp permite que los elementos salten a una nueva linea si ya no entran en el contenedor

flex-grow, flex-shrink, flex-basis

Las propiedades flex-grow, flex-shrink y flex-basis permiten delimitar cuanto es el tamaño base de una etiqueta hija del flex, ademas de delimitar cuanto pueden crecer y cuanto pueden encogerse

align-self

La propiedad align-self permite controlar la alineacion vertical de los elementos hijos de forma independiente
