JavaScript DOM

El DOM (Document Object Model) permite cambiar la estructura de una pagina web en tiempo real, capaz de crear codigo HTML y CSS

Metodos de Seleccion Clasicos

Para seleccionar objetos dentro de un HTML existieron selectores como el getElementByID y getElementsByTagName

getElementByID

El getElementByID permite seleccionar un unico elemento de todo el documento donde el ID proporcionado en el js coincida con el ID del objeto. Es la forma mas rapida y sencilla de obtener un solo objeto en especifico

getElementsByTagName

El getElementsByTagName permite seleccionar una coleccion de varios elementos cuando estos comparten la misma etiqueta

Metodos de Seleccion Modernos

Para simplificar la forma de encontrar elementos se introdujeron nuevos metodos de seleccion que permiten usar de mejor manera los selectores clasicos

querySelector

El querySelector recibe un selector en formato CSS y devuelve unicamente el primer elemento que coincida con dicho patron

querySelectorAll

El querySelectorAll recibe un selector en formato CSS y devuelve todos los elementos que cumplan esa condicion en el documento
