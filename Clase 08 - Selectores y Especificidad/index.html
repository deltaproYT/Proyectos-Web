Selectores y Especificidad

Tipos de Selectores

Los selectores son atributos que nos permiten dirigirnos hacia uno o varios elementos a la hora de decorar con el CSS, dentro de los selectores existen

  • Selectores de Etiqueta
  • Selectores de Clase
  • Selectores de ID

Selectores de Etiqueta

Los selectores de etiqueta son selectores que funcionan con todas las instancias de un tipo de etiqueta en todo el documento html

Por ejemplo yo usare la etiqueta span para hacer la demostracion

Haremos que esta etiqueta tenga un color azul-violeta con una fuente arial

Codigo usado:

span { color: blueviolet; font-family: Arial; }

Selectores de Clase

Los selectores de clase son selectores que funcionan con todas las instancias que pertenezcan a una clase en especifico, la clase se define gracias al atributo class="" dentro de cualquier etiqueta, todas las etiquetas con la misma clase asignada pertenecen a esa clase

Codigo usado:

.clase {atributos}

Este texto a la clase resaltado

Este texto pertenece tambien a la negrita

Este texto tambien a la clase resaltado

Selectores de ID

Los selectores de ID son selectores que funcionan con la instancia que tenga el identificador seleccionado, se utiliza solo con una sola instancia en especifico

Por ejemplo hare que el siguiente parrafo tenga un subrayado con cursiva

Codigo usado:

#ID {atributo}

Este texto tiene un identificador unico
