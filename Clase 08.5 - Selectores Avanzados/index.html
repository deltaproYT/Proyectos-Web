Selector de Atributos

El selector de atributos como su nombre indica, selecciona instancias por sus atributos, en mi caso voy a seleccionar todas las instancias que tengan la palabra box en su clase para ponerle una tipografia arial y un fondo cian

El uso de *= hace que no busque coincidencias exactas sino que busque coincidencias parciales, en caso de no usarlo, la pagina solo buscara las coincidencias totales

Comando Utilizado:

div[class*="box"] { font-family: Arial; background-color: aqua; }

Selector de Hijo Directo

El Selector de hijo directo permite seleccionar solo los herederos de la etiqueta padre que hayan sido especificados, de ese modo no heredar el estilo a modelos que no lo necesitan

En este caso pondre tipografia Georgia a todo el nav, pero solo le pondre borde verde al div y al p

Comando Utilizado:

nav { font-family: Georgia; } nav > div > p { margin: 15px; border: solid lightgreen 25px; }

Selector de Hermanos Adyacentes

Los operadores de Hermanos adyacentes son 2, el "+" selecciona a la siguiente instancia hermana, mientras que el operador "~" elige a todos los hermanos generales posteriores

En este caso utilizare el operador + en el iem 2 asignandole a la siguiente instancia el color aquamarina junto con un margen superior de 20px, mientras que utilizare el operador "~" en el item 7 para asignar a las siguientes instancias el color chocolate y asignar un margen superior de 5px

Comando Utilizado:

#item2 + li { color: aquamarine; margin-top: 20px; } #item7 ~ li { color: chocolate; margin-top: 5px; }

Pseudoclases de Estado y Estructurales

Las Pseudoclases de estado y estructurales permiten seleccionar objetos durante un estado temporal

Pseudoclases de Interaccion y Estado

:hover

La pseudoclase :hover realiza un cambio de estilo solo al mantener el cursor encima de la instancia

En este caso creare un div que al pasar el cursor encima de el va a cambiar su color por el rojo y su texto por el blanco

Comando Utilizado:

#hover-div:hover { background-color: red; color: white; }

Hola Mundo !!!

:active

La pseudoclase :active realiza un cambio de estilo solo al mantener el click encima de la instancia

En este caso creare un div que cuando haga click su color cambiara por el verde lima y el texto en negro

Comando Utilizado:

#active-div:active { background-color: lime; color: black; }

Adios Mundo!!!

:focus

La pseudoclase :focus realiza un cambio de estilo solo cuando un campo de texto se encuentra activo

En este caso creare un input de tipo "text" donde al tenerlo activado dibujaremos un borde naranja con fondo lima con transparencia de 0.2

Comando Utilizado:

#focus-input:focus { background-color: rgba(47, 255, 0, 0.2); border: solid 1px rgb(255, 182, 46); }

Pseudoclases Estructurales

:first-child y :last-child

Las pseudoclases first-child y last-child funcionan en listas (ul - ol) donde first-child va a afectar al primer item dentro de la lista mientras last-child afecta al ultimo item de la lista

Comando Utilizado:

#first-last-ul > li:first-child { background-color: purple; color: white; } #first-last-ul > li:last-child { background-color: yellow; }

:nth-child(n)

La pseudoclase nth-child permite calcular dinamicamente una decoracion tomando en cuenta la posicion

Si se quiere trabajar con la posicion exacta de un objeto se puede reemplazar la "n" por un numero entero referente a la posicion a la que se desea realizar el estilo

En este caso usare el nth-child para seleccionar al segundo hijo de esta clase y le dare el color burlywood junto con el tamaño de fuente en 20px

Comando Utilizado:

.nth-child-ul[id="nth-1"] li:nth-child(2) { font-size: 20px; color: burlywood }

Pseudoclases logicas y relacionales

:is y :where

Cuando se repite mucho una instancia en CSS es mucho mas facil utilizar un :is() o :where(), los cuales permiten agrupar instancias iguales o con base similar, la unica diferencia radica en que el :where() tiene una especifidad de 0, es decir que cualquier cambio posterior se superpone al where

:not

El :not() permite excluir elementos cuyos elementos coincidan con un selector especifico dentro del parentesis

:has

El :has() identificar instancias padre segun las instancias hijas que tenga en su interior

Pseudoelementos para estilizar

A diferencia de las pseudoclases los pseudoelementos actuan directamente sobre fragmentos especificos de un elemento o que permiten inyectar caracteristicas visuales

Partes Especificas

Modifican porciones concretas del texto como:

::first-letter

Afecta solo al primer caracter de la instancia

En este caso pondre una tipografia arial y tamaño de 25px a la primera letra

Comando Utilizado:

#first-letter-p::first-letter { font-family: Arial; font-size: 25px; }

Contenido Dinamico

Permiten insertar elementos dinamicos antes o despues del contenido real utilizando la propiedad content

::before y ::after

Mientras que before permite insertar elementos dinamicos antes del texto real, after permite insertar elementos dinamicos despues del texto real
