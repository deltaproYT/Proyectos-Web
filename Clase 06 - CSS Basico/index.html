Colores

Los colores en CSS se pueden definir de diferentes formas como:

  • Palabras Clave

    • Red-Yellow-Green-Blue

  • Colores en Hexadecimal

    • #FF0000-#FFFF00-#00FF00-#0000FF

  • Colores en RGB y RGBA

    • (255, 0, 0)-(255, 255, 0)-(0, 255, 0)-(0, 0, 255)

Las principales propiedades que trabajan con colores son la propiedad color y background color

color

La propiedad color, cambia el color del texto que se encuentre dentro del contenedor

background-color

La propiedad background-color cambia el color del fondo del contenedor

Ejemplo: un cuadro con texto azul y fondo verde

Tipografia

Para controlar como se dibuja el texto, contamos con la tipografia.

Las propiedades de la tipografia son:

  • font-family

    • La propiedad de font-family se encarga de controlar la tipografia usada en el texto

  • font-size

    • La propiedad de font-size se encarga de controlar el tamaño de la tipografia del texto

Ejemplo: texto con fuente roboto (no preinstalado por defecto) y tamaño de fuente de 16px
