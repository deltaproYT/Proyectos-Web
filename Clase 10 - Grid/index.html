Grid

El Grid es un sistema de alineación basado en 2 dimensiones (horizontal y vertical), en rasgos simples es una version mucho mas avanzada de flexbox, que en lugar de operar en un eje opera en 2 formando una cuadricula

Para activar el Grid se utiliza el atributo css display:

display: grid;

repeat()

La funcion repeat() es importante, pues dentro de los atributos grid, facilitan el no repetir datos innecesariamente

Se usa mucho al crear las columnas y las filas, pues normalmente se declaran unas detras de otras (100px 20px 300px) pero en casos donde todas las columnas o filas son del mismo tamaño es mas facil utilizar el comando repeat; "grid-template-columns: repeat(3, 100px);" este comando crea 3 columnas de ancho 100px

fr

El grid añade una medida nueva conocida como fraccion o fr, siendo una unidad de medida flexible que se ajusta proporcionalmente al espacio de la cuadricula

grid-template-columns y grid-template-rows

Los atributos grid-template-columns y grid-template-rows son los atributos mas importantes dentro del grid, pues estos son los encargados de la creacion de las columnas y las filas dentro del grid

minmax()

La funcion minmax() es una funcion que permite establecer el maximo o minimo que puede crecer una cuadricula permitiendo que se adapte de forma automatica

autofill y autofit

autofill y autofit son modificadores que se usan dentro de la funcion repeat() que sirven para crear columnas y filas de forma responsiva para ajustarse a las dimensiones de la pantalla

Mientras autofill utiliza columnas vacias para abarcar el ancho de la pantalla, autofit aumenta el ancho de las columnas ya existentes para abarcar el ancho de la pantalla

gap

El atributo gap se encarga de definir el espaciado que existe entre las celdas de la cuadricula sin afectar sus margenes o padding

grid-column y grid-row

Los atributos grid-column y grid-row permite posicionar o expandir un elemento hijo especificando las lineas de la cuadricula donde empieza y termina o utilizando la palabra clave span para indicar cuantas celdas abarcar

grid-template-areas y grid area

Los atributos grid-template-areas y grid area permiten organizar la interfaz asignando nombres visuales a las secciones

subgrid

El atributo subgrid Permite que una cuadricula anidada herede y respete exactamente las mismas lineas y pistas de su contenedor padre
